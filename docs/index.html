You use coding agents every day.
Build one.

Six short lessons that take you from a single model call to a small coding agent that plans, reads your code, asks before it edits, and checks its work with your tests. The loop and its tools come to about 250 lines.

Start lesson 1 Get the code
npm run agent

No API key to start

Every lesson runs in replay mode with pre-written model replies. The loop, the tools and the tests are real. Add a key to run it live against Claude.

No framework

Just the official Anthropic SDK and a while loop. Once you know what frameworks do for you, picking one gets much easier.

Safe by default

The agent works on a throwaway copy, can't leave the project folder, and asks you before every edit.

The lessons

1 Text in, text out Tool calling with no tools API. Just a prompt and an if. 2 Your first real tool call Schemas, tool_use, tool_result, and where one round runs out. 3 Keep going until it's done Let the model take as many rounds as it needs. 4 Give it a to-do list The checklist trick from coding agents, in one tool. 5 Guardrails: the boring code that matters Sandboxed paths, recoverable errors, approvals, limits. 6 A mini coding agent All of it together, fixing a real failing test. + Do you even need an agent? Workflows vs agents, and a 4-question checklist.

Run it in a minute

git clone https://github.com/georgehanu/the-agent-loop.git
cd the-agent-loop
npm install
npm run lesson1

Node.js 20 or newer. That's it.
